# Activos de marca

Los SVG actuales son identificadores temporales construidos para la primera versión.
Pueden reemplazarse conservando estos nombres y dimensiones proporcionales:

- `logo-horizontal.svg`: versión para fondos claros.
- `logo-horizontal-light.svg`: versión para fondos oscuros.
- `logo-mark.svg`: isotipo cuadrado.
- `logo-monochrome.svg`: versión de un solo color.
- `favicon.svg`: favicon temporal.

No elimines los archivos hasta actualizar las referencias en `src/config/site.ts`.
